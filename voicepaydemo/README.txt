AsiaPay Voice Pay + Lucky Draw Prototype v7.5

Files:
- voice-pay.html: Guest Voice Pay flow
- lucky-draw.html: Lucky Draw game
- lucky-draw-dashboard.html: Lucky Draw dashboard
- voice-pay-dashboard.html: Manage A-E gift names, images, show-image and prices

- Lucky Draw settings continue using asiapayLuckyDrawConfigV2. This is a static demo, not a real payment integration.
